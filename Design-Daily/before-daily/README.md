# 象素之间 · 历史日报归档

按云存储容量从最早可完整保存的期刊归档，包含中文正文、来源链接、期刊关系和本地图片。总入口为 index.html，后续批次在 batches/ 下独立保存；根目录 data.json、data.js 和 images/ 是首次归档，继续保留。

下载完整 before-daily 目录后，可打开 index.html 选择批次。也可在此目录运行 python3 -m http.server 8080，再访问 http://127.0.0.1:8080。图片以相对路径加载；原文与外部视频需要联网。

assets.json 提供图片字节数和 SHA-256，每个后续批次有独立的同名清单。归档只用于历史及本地阅读，不依赖微信访问此域名。
